# 새마을금고중앙회 신입직원 강의안 HTML

문서코드: `MG-LAW-LECTURE-2026-INTRA-GH`

## GitHub Pages 배포 방법

1. 이 ZIP 파일을 압축 해제합니다.
2. `index.html`, `.nojekyll`, `README.md`를 GitHub 저장소 루트에 업로드합니다.
3. GitHub 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Deploy from a branch**를 선택합니다.
5. Branch는 `main`, Folder는 `/root`로 설정합니다.
6. 배포 완료 후 제공되는 Pages URL로 접속합니다.

## 사용 방법

- 발표 시작: 첫 화면의 `발표 시작`
- 다음 단계/다음 슬라이드: Space, Enter, →, PageDown
- 이전 단계/이전 슬라이드: ←, PageUp, Backspace
- 전체보기: O
- 인쇄 모드: P 또는 첫 화면의 인쇄 버튼
- 스타일 전환: T(토스), K(카카오)
- 스포트라이트: S
- 원하는 슬라이드로 이동: 우측 번호 입력창에 번호 입력 후 Enter 또는 이동

## 인쇄

- 브라우저에서 `Ctrl+P`를 누르면 인쇄할 수 있습니다.
- URL 뒤에 `#print`를 붙이면 인쇄 모드가 자동 적용되고 인쇄창이 열립니다.
  예: `https://계정.github.io/저장소명/#print`
